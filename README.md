## Currently

- **CoSE Monitoring** — Prometheus, Thanos and Grafana watching hundreds of machines, alerting within minutes, run as a 3-node HA cluster tested by killing nodes one at a time. Targets managed from NetBox, Grafana config git-synced.
- **Alert-subscription portal** (PHP/Laravel) — each team subscribes to the alerts that concern them, behind University SSO with RBAC and proxy auth for Prometheus, Grafana, Thanos and Alertmanager.
- **CI/CD** — a GitHub Actions pipeline that takes a merge to production in about 12 minutes; Ansible roles for adding, migrating and tearing down nodes.

## Homelab

n8n for automations, Pi-hole, Penpot, a few custom personal apps and Prometheus + Grafana watching all of it, reachable from anywhere over Tailscale. This is also a setup where I test stuff on VMs, learn DevOps.
